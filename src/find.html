How to read the tags

How to read this list. A Read on official site tag means we opened the program’s own page. It does not mean that page gave every age, pay or date, so check those with the program before you plan around them. Confirm first means we found it but could not read the official page, so check it yourself before you plan around it. Programs that already closed are still here with the month they usually reopen. A Based on last year tag means the date follows last cycle's pattern, and the program has not posted new dates yet.
