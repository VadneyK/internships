# Security and safety

## Site security
This is a static website with no accounts, forms that send data, or server. If you find a problem such as a script that could
run something it should not, use GitHub's private vulnerability reporting: **Security tab, "Report a vulnerability"**.

## Safety of young contributors
Many contributors are teenagers. See `CODE_OF_CONDUCT.md`. If something in an issue or pull request makes you uncomfortable,
use GitHub's "Report content" menu on that comment, and tell a parent or trusted adult.
